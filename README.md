# Pokémon ROM Randomizer

Een randomizer die volledig lokaal in de browser draait. Je laadt je eigen (ontsleutelde) ROM en krijgt alleen de opties die voor die game werken.

## Ondersteunde games
- **Game Boy / Color:** Rood/Blauw/Geel, Goud/Zilver/Kristal
- **GBA:** Ruby/Sapphire/Emerald, FireRed/LeafGreen
- **Nintendo DS:** Diamond/Pearl/Platinum, HeartGold/SoulSilver, Black/White, Black 2/White 2
- **3DS:** X/Y, Omega Ruby/Alpha Sapphire, Sun/Moon, Ultra Sun/Ultra Moon

## Gebruik
1. Start `start.bat` (of open `index.html` in een browser).
2. Sleep je ROM op de pagina, kies de opties en klik op **Randomize & download**.
3. 3DS: kies een volledige `.3ds`, een LayeredFS-map (Luma/Azahar-mods) of verstuur via FTP naar je 3DS.

ROMs worden **niet** meegeleverd en horen niet in deze repository (zie `.gitignore`).
